# Project instructions

- Keep the launcher compatible with Android 9 (API 28), 1 GB RAM and remote-only operation.
- Write source, comments and documentation in English. Localize owned UI strings in Android resources.
- Require explicit approval for physical device installation, HOME default changes, system app changes, destructive operations or external publication. Firmware, recovery, bootloader and system partitions are outside launcher scope.
- Exclude device identifiers, credentials, signing keys, raw captures and firmware backups from Git. Review staged changes before committing.
- Record test results, failures, limitations and the next validation step for each phase.
